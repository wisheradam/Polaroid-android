# 0.2.0 real-device acceptance

Keep the v1 checklist as well. Back up a populated v1 debug install before any certificate migration.

- Switch rear/front/rear on the main screen repeatedly; verify preview, available-lens fallback, unchanged film count, cartridge type and archive. Try switching during charging, capture and ejection; it must be disabled.
- Capture an asymmetric selfie (readable text or a left/right marker) in portrait and landscape. Verify saved/exported/shared mirroring matches the front preview and rear photos remain unmirrored.
- Front camera: test Off, Screen flash, Edge light and Screen + edge. Verify white/warm-white choice and practical illumination. At least one LCD and one OLED display should be tested.
- With screen flash, verify the display illuminates before capture, AE has time to react and the light stays on through exposure. It must clear before development/ejection UI takes over. The flash overlay must not appear in the JPEG.
- Edge mode: test width/brightness extremes, cutouts, rounded corners, small screens, landscape and large text. Keep preview/control accessibility. Disable, switch lens, leave the camera, lock/background, interrupt with a call and rotate during a flash; brightness must restore every time.
- Test Light, Dark and Follow System on every screen, settings, menus, dialogs, system bars and corkboard. Change the OS theme while the app is running. Film paper, photograph colors and cork must not invert. Restart and verify persistence.
- Complete and share one photo in each format from both Archive and detail. Test installed Instagram/Facebook/Lite and missing/disabled apps, cancelled composers and the Sharesheet fallback. Inspect the original full-resolution framed JPEG. Unfinished photographs must never expose sharing actions.
- Recheck ten-shot depletion, manual reload, shake-only development and paused progress, resumed archive, ejection audio/haptics, pin locking, rotation/overlap and board persistence after the update.
